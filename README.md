# Worship Player & Telegram Bot Suite

یک سیستم جامع جهت مدیریت، دریافت و پخش ادعیه، سوره‌ها و زیارات از گوگل درایو از طریق ربات تلگرام و اپلیکیشن اندروید فلاتر.

## ساختار پروژه (Repository Structure)

```
worship_player/
├── bot/                # ربات اختصاصی پایتون تلگرام جهت دریافت لیست و هماهنگی با گوگل درایو
│   ├── config.py
│   ├── main.py
│   ├── services/
│   │   ├── google_drive_service.py
│   │   └── text_normalizer.py
│   ├── requirements.txt
│   └── .env.example
│
└── app/                # اپلیکیشن کلاینت اندروید توسعه‌یافته با فلاتر (Flutter 3.x)
    ├── lib/
    │   ├── core/       # تم، ثابت‌ها، رنگ‌ها و تنظیمات
    │   ├── data/       # مدل‌ها و فراخوانی داده از درایو و حافظه محلی
    │   ├── logic/      # مدیریت استیت، پلیر و دانلودر
    │   └── presentation/ # صفحات UI و ویجت‌های تعاملی
    └── android/
```

## نحوه کار سیستم
۱. کاربر لیست ادعیه و سوره‌ها را در ربات تلگرام ارسال می‌کند (مثلاً: `یاسین، لقمان، جن`).
۲. ربات متون را نرمال‌سازی کرده و در فایل `index.txt` درایو جستجو می‌کند.
۳. ربات فایل `playlist.json` را به همراه مشخصات فایل و لینک استریم در گوگل درایو به‌روزرسانی می‌کند.
۴. اپلیکیشن فلاتر آخرین لیست را دریافت کرده، امکان پخش آنلاین با کنترل سرعت و دانلود جهت پخش آفلاین را برای کاربر فراهم می‌سازد.

## فرآیند کامپایل ابری و انتشار خودکار (CI/CD GitHub Actions)

جهت جلوگیری از دانلود ابزارهای سنگین و آلوده‌شدن سیستم محلی، کامپایل فایل نصبی اندروید (APK) به طور کاملاً ابری از طریق **GitHub Actions** انجام می‌شود:

### روش اول: انتشار خودکار با تگ نسخه
هر زمان که یک تگ نسخه (مثلاً `v1.0.0`) در گیت ثبت و پوش شود:
```bash
git tag v1.0.0
git push origin v1.0.0
```
ورک‌فلو به صورت خودکار اجرا شده، تست‌ها را پاس می‌کند، فایل `worship-player-release.apk` را کامپایل کرده و در بخش **Releases** گیت‌هاب قرار می‌دهد.

### روش دوم: اجرای دستی از طریق پنل گیت‌هاب
از تب **Actions** در مخزن گیت‌هاب، ورک‌فلو `Build and Release Android APK` را انتخاب کرده و دکمه **Run workflow** را بزنید تا فایل APK مستقیماً تولید و ضمیمه شود.
